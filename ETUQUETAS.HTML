ETIQUETAS HTML
Categorías Etiqueta Nombre o Signifcado Descripción Principales usos
Contenedores <div> División Define una sección o contenedor genéricos. Agrupa elementos para aplicar estilos o scripts.
<span> Span Define un contenedor en línea genérico. Aplica estilos o scripts a fragmentos de texto.
Estructura del documento <body> Cuerpo del Documento Contiene el contenido visible de la página web. Muestra el contenido principal de la página.
<html> HTML ELEMENTO raiz de un documento HTML. Contiene todo el contenido de la página web.
Formularios <button> Botón Define un Botón Interactivo. Crea botones para enviar formularios, enviar razones, etc.
<form> formulario Define un formulario para la entrada de datos. Crea formularios para recopilar información del usuario.
<input> Entrada de formulario Define diferentes tipos de campos de entrada. Crea campos de texto, botones, casillas de verificación, etc.
Listas <li> Elemento de lista Define un elemento dento de una lista. Representa un elemento individual en una lista.
<ol> Lista ordenada Define una lista de elementos con orden específico. Crea listas numeradas.
<ul> Lista no ordenada Define una lista de elementos con orden específico. Crea listas con viñetas.
Metadatos <!DOCTYPE> Declaración de tipo de documento Define el tipo de documento de HTML. Indica la versión de HTML que se esta utilizando.
<head> Encabezado del documento Contiene metadatos e información sobre el documento. Define el título de la página, enlaces a hojas de estilos, etc.
<link> Enlace a recursos externos Enlaza a hojas de estlos CSS, íconos, etc. Conecta archivos externos a la página web.
<meta> Metadatos Proporciona metadatos sobre el documento HTML. Define la codificación de caracteres, palabras clave, Descripción, etc.
<title> Título del documento Define el título de la página que se Muestra en la barra de título del navegador.
<style> Estilos CSS Internos Define estilos CSS directamente en el documento HTML. Aplica estilos a los elementos HTML
Multimedia <audio> Audio Inserta un reproductor de audio. Reproduce audio en la página web.
<canvas> Lienzo Define un área para gráficos dinámicos. Crea gráficos y animaciones con Js.
<frame> Marco en línea Inserta otro documento HTML dentro del documento actual. Incrusta contenidos en otras páginas webs.
<img> Imagen Inserta una imagem en la página. Muestra imagenes en la página web
<svg> Gráfico Vectorial Escalable Inserta gráficos vectoriales. Muestra gráficos vectoriales escalables.
<VIDEO> Video Inserta un reproductor de video. Muestra videos en la página web.
Secciones <VIDEO> Video Inserta un reproductor de video. Muestra videos en la página web.
<article> Artículo Define un artículo independiente. Representa contenido independiente como un artículo de blog.
<aside> contenido secundario Define contenido secundario o complementario. Muestra barras laterales, anuncios,etc..
<footer> Pie de página Define el pie de página de una sección o página. Contiene información introductoria o de navegación.
<header> Encabezado de sección Define el Encabezado de una sección o página. Contiene información introductoria o de navegación.
<nav> navegación Define una sección de enlaces de navegación. Crea menús de navegación. <section> Sección Define una sección genérica dentro de un documento. Agrupa contenido relacionado temáticamente.
Tablas <Tablas> Encabezado de sección Define el Encabezado de una sección o página. Contiene información introductoria o de navegación.
<main> contenido principal Define el contenido principal de la página. Contiene el contenido central de la página.
